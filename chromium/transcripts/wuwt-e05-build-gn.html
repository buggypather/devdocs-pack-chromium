And so we wrote on ELF linker, which is the file format used on Linux and Android, and on COFF linker, which is the file system used on Windows, and our own Mach-O linker, which is the file system on Apple - macOS and iOS. And our linkers are way, way, way faster than the things that they replace. On Windows, we were, like, 10 times faster than the Windows linker. And on Mac, we're, like, four times faster than the system linker and whatnot. The other linker vendors have caught up a little bit, but we - I feel like Chrome has really advanced the state and performance of linking binaries across the industry, which I think is really cool.
