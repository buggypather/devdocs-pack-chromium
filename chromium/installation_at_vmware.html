How to install Chromium OS on VMWare

Download

  1. Download VMware player
  2. Create a gtgt.com account and download Chrome image

Mounting

  1. Create a New Virtual Machine
  2. Do not selecting any OP-sys (other-other-etc)
  3. Delete your newly created hardisc (lets say you named it as Chrome)
  4. Move downloaded harddisc to the same folder as other VMware files for this Virtual Machine
  5. Rename your downloaded hardisc to newly created Virtual Machine original name (in my example it was Chrome)
  6. Boot the Chrome Virtual Machine (recommended to use NAT network configuration)
