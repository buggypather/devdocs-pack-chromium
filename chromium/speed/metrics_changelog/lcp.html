Largest Contentful Paint Changelog

This is a list of changes to Largest Contentful Paint.

  • Chrome 153
    • Metric bug fix: Fixed race conditions in presentation timestamp attribution for animated images and first video frames (8178904, 8177704).
  • Chrome 151
    • Launch feature: Prompt LCP entry emission for video elements (RequestMainFrameAfterFirstVideoFrame)
    • Metric bug fix: Prevent premature garbage collection of VideoTiming metadata to ensure video LCP entries are accurately reported (7911270).
  • Chrome 147
    • Metric definition improvement: Emit LCP candidates based on largest painted image instead of largest pending image
  • Chrome 145
    • Launch feature: Shipped PaintTimingMixin exposing standard paint timing properties across entry types (7224616).
  • Chrome 144
    • Metric bug fix: Corrected LCP and FCP handling when document opacity changes from zero to non-zero (7137609, 7164696).
  • Chrome 143
    • Metric bug fix: Fixed text presentation timestamps reporting too early, impacting LCP (introduced in M140)
  • Chrome 140
    • Bug: Text presentation timestamps reporting too early, impacting LCP
  • Chrome 133
    • Implementation optimizations: Expose coarsened cross-origin renderTime in element timing/LCP (regardless of TAO)
  • Chrome 130
    • Launch feature: Exclude transparent text from being LCP eligible
  • Chrome 126
    • Launch feature: Enable NewPresentationFeedbackTimeStamps on Mac to improve the accuracy of the frame display time
  • Chrome 118
    • Implementation optimizations: Image loading prioritizations
  • Chrome 117
    • Bug: Spurious LCP entries after user interaction
  • Chrome 116
    • Metric definition improvement: Changes to how LCP handles videos and animated images
    • Implementation optimizations: Optimizing image load scheduling
  • Chrome 112
    • Metric definition improvement: Largest Contentful Paint ignores low-entropy images
  • Chrome 111
    • Implementation optimizations: Changes related to LCP, FCP and Paint Holding
  • Chrome 99
    • Implementation optimizations: Navigation optimizations and timeOrigin changes
  • Chrome 98
    • Metric bug fix: Text paints are more accurate
  • Chrome 96
    • Metric bug fix: Largest Contentful Paint uses the page viewport
  • Chrome 88
    • Metric definition improvement: Largest Contentful Paint ignores full viewport images
    • Metric definition improvement: Largest Contentful Paint stops recording after input in an iframe
    • Metric definition improvement: Largest Contentful Paint bug fix for some images with source changes
    • Metric definition improvement: Largest Contentful Paint ignores removed content by default
  • Chrome 86
    • Metric definition improvement: Largest Contentful Paint ignores paints with opacity 0
  • Chrome 83
    • Metric definition improvement: Largest Contentful Paint measurement stops at first input or scroll
    • Metric definition improvement: Largest Contentful Paint properly accounts for visual size of background images
  • Chrome 81
    • Metric definition improvement: Largest Text Paint correctly reported while largest image is loading
  • Chrome 79
    • Metric is elevated to stable; changes in metric definition will be reported in this log.
  • Chrome 77
    • Experimental metric exposed via API: Largest Contentful Paint available via PerformanceObserver API
