First Input Delay Changelog

This is a list of changes to First Input Delay.

  • September 9, 2024
    • Deprecated in favor of Interaction to Next Paint
  • Chrome 91
    • Chrome change affecting metric: Disable double-tap-to-zoom on mobile viewports
  • Chrome 83
    • Metric definition improvement: First Input Delay includes inputs with delays < 1ms in Chrome User Experience Report
  • Chrome 77
    • Metric exposed via API: First Input Delay available via Event Timing API
  • Chrome 75
    • Metric definition improvement: First Input Delay includes input events that had previously been filtered
