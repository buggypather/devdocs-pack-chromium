Interaction to Next Paint Changelog

This is a list of changes to Interaction to Next Paint.

  • Chrome 150

    • Metric bug fix: Nested clicks (such as <label> clicks forwarding to form controls) assigned interactionId = 0 to align with web standards (7870025).

  • Chrome 148

    • Metric bug fix: Report only web-exposed event targets in Event Timing

  • Chrome 147

    • Metric definition improvement: Early interaction ID assignment and context menu fallback

  • Chrome 144

    • Launch feature: Launch performance.interactionCount API to stable

  • Chrome 135

    • Metric definition improvement: Updated interactionId type to unsigned long long (uint64_t) per W3C specification (6300797).

  • Chrome 134

    • Implementation optimizations: Defer non-urgent renderer tasks after input by default

  • Chrome 133

    • Launch feature: Enable EventTimingSelectionAutoScrollNoInteractionId by default

  • Chrome 130

    • Launch feature: Enable EventTimingTapStopScrollNoInteractionId by default
    • Launch feature: Enable EventTimingHandleKeyboardEventSimulatedClick by default
    • Launch feature: Enable ReportEventTimingAtVisibilityChange by default

  • Chrome 129

    • Launch feature: Enable ContinueEventTimingRecordingWhenBufferIsFull by default

  • Chrome 128

    • Metric bug fix: Enable EventTimingHandleOrphanPointerup by default

  • Chrome 127

    • Launch feature: Enable EventTimingKeypressAndCompositionInteractionId by default
    • Launch feature: Enable EventTimingFallbackToModalDialogStart by default

  • Chrome 126

    • Launch feature: Enable NewPresentationFeedbackTimeStamps on Mac to improve the accuracy of the frame display time

  • Chrome 122

    • Launch feature: Enable EventTimingMatchPresentationIndex by default

  • Chrome 121

    • Metric bug fix: Event Timing flush pointerdown & keydown on contextmenu

  • Chrome 116

    • Metric bug fix: Event Timing - Fallback artificial events ending time to processingEnd

  • Chrome 112

    • Metric bug fix: Event Timing Pointer Map Flush Timer Bug Fixes

  • Chrome 111

    • Metric bug fix: Event Timing API no longer reports very long durations when interaction leads to "open in new tab"

  • Chrome 109

    • Implementation optimizations: A change in Chrome to prioritize compositing after input events caused a significant improvement to INP

  • Chrome 96

    • Experimental metric exposed via API: Event Timing InteractionID available via PerformanceObserver API
