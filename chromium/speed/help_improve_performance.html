Chrome is slow, what do I do?

How to file a bug

  • File a bug. To file a bug, please use the speed bug template.
  • Attach a trace. The best way to get performance data to developers is to include a trace, so please follow these instructions to record a trace and attach it to the bug.
  • Try TraceOnTap the TraceOnTap Extension makes it easier to record traces and attach them to bugs. Source code
